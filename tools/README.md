# Tools (`tools`)

## Overview
Offline asset generation, multi-layer dealer puppet rigging, faceplate de-occlusion, and Win32 GDI (`PrintWindow`) visual verification capture scripts for the Blackjack desktop application. These scripts synthesize 1x and 2x HiDPI sprite sheets, stage backdrops, cursed cards, procedural audio accents, and automated dialog/stage screenshots.

## Invariants
- `[tools/build_character_layers.py:generate_character_layers]` and `[tools/deocclude_dealer_faceplates.py:deocclude_and_build_character]`: Generate 19 discrete puppet layers (`shadow`, `neck`, `torso`, `head`, `eyes_open`, `eyes_half`, `eyes_closed`, `mouth_neutral`, `mouth_talk`, `mouth_smirk`, `mouth_gasp`, `mouth_a`, `mouth_o`, `mouth_e`, `mouth_f`, `arm_rest`, `arm_deal`, `arm_peek`, and composite `bust`) at both 1x (`112x112` px) and 2x (`224x224` px) RGBA resolutions.
- `[tools/build_roster_puppet_assets.py:apply_unpremultiplied_mask]` and `[tools/deocclude_dealer_faceplates.py:apply_unpremultiplied_mask]`: Multiply alpha channel by normalized grayscale mask without black RGB premultiplication, zeroing RGB only where resulting `alpha == 0`.
- `[tools/build_roster_puppet_assets.py:put_unpremultiplied_alpha]` and `[tools/deocclude_dealer_faceplates.py:put_unpremultiplied_alpha]`: Propagate nearest non-zero neighbor RGB values into blurred border pixels (`orig_a == 0` and `blurred_a > 0`) to prevent dark fringes, and zero RGB where `blurred_a == 0`.
- `[tools/build_haunted_assets.py:process_cards]`: Generates `card_13.png` matching host deck geometry (`74x107` px) with 13 skull pips and preserves existing `back_haunted.png` unless `--force` is passed or the file is absent.
- `[tools/build_character_roster_assets.py:synthesize_wav]` and `[tools/build_haunted_assets.py:synthesize_audio]`: Clamp waveform samples to `[-1.0, 1.0]` and encode 1-channel, 16-bit mono PCM WAV audio at `44100` Hz.
- `[tools/build_pixel_logo.py:create_pixel_logo]`: Renders on a `156x28` virtual grid where each cell is `3 * scale` pixels (`468x84` at 1x and `936x168` at 2x) with strict coordinate bounds (`0 <= gx < grid_w` and `0 <= gy < grid_h`).
- `[tools/build_stage_backdrops.py:create_casino_backdrop]` (and `create_creep_backdrop`, `create_hell_backdrop`, `create_celestial_backdrop`, `create_crypt_backdrop`): Convert composited RGBA backdrops to 100% opaque RGB images (`1000x140` at 1x, `2000x280` at 2x).
- `[tools/capture_dialogs_verification.py:capture_hwnd_to_image]` (and sibling `capture_*.py` scripts): Resolve root ancestor HWND via `GetAncestor(hwnd, 2)` and fall back from `PrintWindow(..., 2)` (`PW_RENDERFULLCONTENT`) to `PrintWindow(..., 0)` if flag 2 fails.

## Side Effects
- `[tools/build_character_roster_assets.py:CHARACTERS_DIR]`, `[tools/build_character_roster_assets.py:AUDIO_DIR]`, `[tools/build_dummy_puppet_assets.py:DUMMY_DIR]`, `[tools/build_haunted_assets.py:HAUNTED_ASSETS_DIR]`, `[tools/build_haunted_assets.py:HAUNTED_AUDIO_DIR]`, `[tools/build_pixel_logo.py:ASSETS_DIR]`, and `[tools/build_stage_backdrops.py:BACKDROPS_DIR]`: Create target asset/audio directories on module import via `mkdir(parents=True, exist_ok=True)`.
- `[tools/build_character_layers.py:generate_character_layers]`, `[tools/build_character_roster_assets.py:build_all_characters]`, `[tools/build_dummy_puppet_assets.py:build_and_save_all]`, `[tools/build_roster_puppet_assets.py:run_pipeline]`, `[tools/build_tiffany_puppet_assets.py:main]`, and `[tools/deocclude_dealer_faceplates.py:run_all]`: Read source bust images and write 1x and 2x character layer PNGs under `assets/haunted/characters/<char_id>/`.
- `[tools/build_haunted_assets.py:process_cards]`, `[tools/build_haunted_assets.py:process_accessories]`, and `[tools/build_haunted_assets.py:synthesize_audio]`: Write cursed card/accessory PNGs to `assets/haunted/` and synthesized `.wav`/`.ogg` audio files to `audio/haunted/`.
- `[tools/build_pixel_logo.py:main]` and `[tools/build_stage_backdrops.py:build_all_backdrops]`: Write 1x and 2x pixel logos to `assets/` and stage backdrops/hanger icons to `assets/haunted/backdrops/` and `assets/haunted/`.
- `[tools/capture_dialogs_verification.py:main]`, `[tools/capture_puppet_demo.py:main]`, `[tools/capture_retro_pixel_verification.py:main]`, `[tools/capture_tiffany_puppet_demo.py:main]`, `[tools/capture_typewriter_demo.py:capture_demo]`, `[tools/capture_universal_puppet_audit.py:generate_audit_sheets]`, `[tools/capture_wardrobe_dummy_demo.py:main]`, `[tools/capture_wardrobe_redesign_verification.py:main]`, and `[tools/capture_welcome_splash_verification.py:main]`: Insert `BASE_DIR` into `sys.path` at import time, instantiate `tkinter.Tk` and `BlackjackApp` with isolated temporary save directories, invoke Win32 `user32`/`gdi32` GDI bitmaps (`GetWindowDC`, `CreateCompatibleBitmap`, `PrintWindow`, `GetDIBits`), and write verification PNG captures to disk.
